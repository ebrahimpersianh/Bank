## ۱. `LiveBackgrounds.kt` — چهار طرح

سه قید در خودِ فایل تحمیل شده‌اند:

- **صفر فایلِ تصویری** — فقط `DrawScope`. هیچ `Color(0xFF..)` در فایل نیست، عمدی.
- **رنگ از پالتِ فعال** — `primary` و `primaryLight` پارامترند. ۱۰ تم × ۴ طرح =
  ۴۰ ترکیب با چهار تابع.
- **آلفا زیرِ ۰٫۰۹** — بالاترین مقدارِ فایل `0.085f` است. **این عددها را بالا
  نبرید**؛ پررنگ‌تر همان شلوغیِ پس‌زمینه‌ی متحرکِ قبلی می‌شود.

```kotlin
// در Scaffoldِ ریشه، **زیرِ** محتوا:
Box {
    LiveBackgroundLayer(
        background = LiveBackground.byId(activeBackgroundId),
        primary = AppPrimary,
        primaryLight = AppPrimaryLight,   // ← نامِ واقعیِ توکن را چک کنید
        isDark = isSystemInDarkTheme() || themeMode == ThemeMode.DARK,
    )
    content()
}
```

🚨 **در `Scaffold`ِ ریشه بکشید، نه در هر صفحه.** با کشیدن در هر صفحه، انیمیشن
در هر تعویضِ تب از صفر شروع می‌شود و پرشِ محسوس می‌دهد. استثنا: تقویمِ تمام‌صفحه
و صفحه‌ی PDF که پس‌زمینه نمی‌گیرند.

### دو چیز که باید خودتان ببندید

۲. **نامِ توکنِ روشن.** من `AppPrimaryLight` نوشتم چون مطمئن نیستم؛ در
`ThemePalette` سه رنگ هست (تیره/اصلی/روشن). هرچه نامِ واقعیِ سومی است همان را
بدهید.

۳. **`dpPx()`ِ آخرِ فایل جای‌نگه‌دار است.** `DrawScope` به `Density` دسترسی
دارد، پس درستش این است:

```kotlin
private fun DrawScope.step28() = 28.dp.toPx()   // DrawScope خودش Density است
```

و در `drawSoftMesh` جایگزینِ `28.dpPx()` شود. دو تابعِ تهِ فایل را حذف کنید.

## ۳. وصله‌ی `ShopScreen.kt` (بخشِ ۶۰ — در مخزن هست)

۱. **دسته‌ی پنجم** `ShopCategory.BACKGROUND` به نوارِ تب، **اولِ** ترتیب (نوعِ
   تازه است و باید دیده شود). چهار ردیف از `LiveBackground.entries`، ولی
   **یک قیمت**: `LiveBackground.BUNDLE_PRICE = 250`. ردیف‌های ۲ تا ۴ بجِ
   «با بسته» می‌گیرند نه قیمتِ جدا.
۲. **کارتِ قلمِ هفته** بالای نوارِ تب، از `featuredItemId(owned)`. `null` =
   کارت نمی‌آید (و پیامِ جانشین **نمی‌آید**).
۳. **قرصِ «مالِ من»** کنارِ شمارشِ کل، **پیش‌فرض خاموش**. فیلتر است نه تبِ ششم —
   همان قاعده‌ی `77a`: ارتفاعِ صفر.
۴. **کارتِ مجموعه** از `SHOP_COLLECTIONS`، زیرِ کارتِ هفته. ردیف‌های قلم‌ها
   **در دسته‌ی خودشان هم می‌مانند** (گروهِ نمایشی، تکرار عمدی است).
۵. ردیفِ `darkOnly` در تمِ روشن بجِ «فقط تمِ تیره» می‌گیرد و انتخاب‌شدنی نیست.

پنج حالتِ ردیف همان `60d` است، بی تغییر.
