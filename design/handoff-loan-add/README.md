# درخواستِ طراحی — مسیرِ «افزودنِ وام» و صفحاتِ بی‌طرحِ بخشِ وام

کاربر با اسکرین‌شات گزارش داد: **دکمه‌ی «+» در تبِ «وام‌های من» به صفحه‌ای می‌رود که هنوز
سبکِ قدیمی دارد** — فیلدهای لختِ حاشیه‌دار، چرخِ تاریخِ سه‌ستونه، بی هیرو، بی سلسله‌مراتب.
کلِ مسیرِ افزودن هنوز از بازطراحی جا مانده.

## اولویت — همین مسیر، به‌ترتیبِ دیده‌شدن

| فایل | چیست | وضعیت |
|---|---|---|
| `AddManualLoanScreen.kt` (۲۹۹ خط) | فرمِ «افزودنِ وام دستی» — همان صفحه‌ی اسکرین‌شات. **ویرایشِ وام هم همین فایل است** (`editingLoan`) | بی‌طرح |
| `CalculatorHostScreen.kt` | میزبانِ تبِ «محاسبه‌گر» (سگمنتِ قسط‌وسود / توانِ بازپرداخت) | `27f` دارد، ولی محتوایش نه |
| `BankLoanScreen.kt` (۷۸۴ خط) | حالتِ «قسط و سود» — قرص‌های نوعِ وام، انتخابِ بانک، اسلایدرها | نیمه |
| `ResultScreen.kt` (۷۹۳ خط) | نتیجه‌ی محاسبه + جدولِ اقساط | بی‌طرح |
| `AffordScreen.kt` (۴۱۰ خط) | «از عهده‌اش برمی‌آیم؟» | `29j` بی‌طرح |
| `DepositScreen.kt` (۲۴۲ خط) | تبِ سپرده | `29n` بی‌طرح |

هر شش فایلِ **فعلی** کنارِ همین README است (نسخه‌ی امروز، نه نسخه‌ی ۱۳ شهریور).

## سه چیزی که در فرم حتماً تکلیفش روشن شود

1. **انتخابگرِ تاریخ** — الان یک چرخِ سه‌ستونه‌ی خام است (روز/ماه/سال) و تنها جای اپ است
   که این شکلی است. فریمِ `29i` («انتخابِ تاریخ») هم هنوز بی‌طرح است؛ **یکی بکش که همه‌جا
   استفاده شود**، نه یکی مخصوصِ این صفحه.
2. **فیلدهای مبلغ** قاعده‌ی قفل‌شده‌ی پروژه را دارند: جداکننده‌ی فارسی `٬` · پسوندِ «ریال» ·
   کپشنِ حروفیِ تومان. این‌ها عوض نمی‌شوند، فقط قابشان.
3. **این فرم دو کار می‌کند** (افزودن و ویرایش). اگر عنوان/دکمه‌ی پایین باید فرق کند، در
   فریم بگو.

## آنچه نمی‌خواهیم

- فرمولِ محاسبه دست نخورد (`core/LoanCalculator.kt` — قرض‌الحسنه با اپِ مرجع تطبیق داده شده).
- دکمه‌ی + هدر اضافه نشود؛ افزودن فقط با FAB است (تاییدِ صریحِ خودت، `27f`).
