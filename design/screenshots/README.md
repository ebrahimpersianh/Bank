# عکس‌های واقعیِ صفحه‌ی «دسترسی به اعلان‌ها» - برای فریمِ `35c`

گوشیِ کاربر: **شیائومی / MIUI**، اندروید با زبانِ رابطِ **انگلیسی**.

| فایل | چیه |
|---|---|
| `notif-access-list-miui.jpg` | فهرستِ اپ‌ها، دو بخشِ `ALLOWED` / `NOT ALLOWED`؛ «جیبک» زیرِ ALLOWED |
| `notif-access-detail-miui.jpg` | صفحه‌ی خودِ جیبک، کلیدِ `Allow notification access` بالای صفحه |

## چیزی که این عکس‌ها ثابت کردن (مهم‌تر از خودِ عکس)

**استدلالِ طراح درست بود.** این عکس‌ها دقیقاً نشون می‌دن چرا **عکسِ ثابت جواب نمی‌ده**:

1. **عنوانِ صفحه «دسترسی به اعلان‌ها» نیست** - رو این گوشی
   `Device & app notifications`ه. یعنی حتی اسمی که تو راهنما می‌نویسیم هم رو
   همه‌ی گوشی‌ها یکی نیست.
2. **زبانِ صفحه انگلیسیه** با اینکه خودِ اپ فارسیه - رابطِ اندروید زبانِ خودش رو داره.
   پس راهنمای فارسی باید **متنِ انگلیسیِ دکمه‌ها رو هم** کنارش بیاره.
3. **دو مرحله‌ست نه یکی**: اول باید «جیبک» رو تو فهرست پیدا کنی، بعد تو صفحه‌ی خودش
   کلیدِ `Allow notification access` رو بزنی.

**نتیجه‌ی طراحی**: راهنما متنی بمونه (تصمیمِ تاییدشده)، ولی حتماً **هر دو مرحله** رو
نشون بده و **اسمِ انگلیسیِ کلید** (`Allow notification access`) رو هم بیاره، چون کاربر
دقیقاً همین رشته رو رو صفحه می‌بینه.

⚠️ این عکس‌ها **مرجعِ داخلی**ان برای طراحی و تست - قرار نیست عیناً تو اپ نشون داده بشن.
