# تقویم من - تقویم فارسی اندروید

اپ تقویم شمسی بومی اندروید (Kotlin + Jetpack Compose)، الهام‌گرفته از اپ iOS «روزگار»، با زبان
طراحی «شیشه» به سبک iOS جدید. برای انتشار تو **کافه‌بازار و مایکت** (نه گوگل‌پلی). این پروژه
**کاملاً جدا از اپ «وام من»** (`native-android/`) تو همین ریپوئه - فقط الگوهای بیلد/CI تاییدشده‌ش
رو به ارث برده.

**نام برند/نمایشی: «تقویم من»** (انتخاب صریح کاربر، هم‌خانواده با «وام من») -
applicationId هم `ir.sadteam.mycalendar`ه. «روزگار» فقط اسم رمز داخلی کد موند (نام پوشه، پکیج
`ir.sadteam.roozegar`، اسم کلاس‌ها) چون تغییرش هیچ اثر کاربری‌ای نداره و فقط ریسک خرابکاری داشت -
جایی که به کاربر نشون داده می‌شه هیچ «روزگار»ی نباید باشه.

پرامپت کامل و فازبندی‌شده‌ی محصول (نسخه‌ی نهایی بعد از ۵ دور نقد) تو تاریخچه‌ی چتِ سازنده‌ست؛
خلاصه‌ی فازها این پایینه.

## وضعیت فازها

### ✅ فاز ۱ - ظاهر (پیاده شده تو همین نسخه)
- **معماری**: دو ماژول - `:core` (Kotlin خالص: تقویم جلالی + گرید ماه + مناسبت‌ها، ۱۰۰٪ تست‌شده و
  قابل اجرا تو سندباکس) و `:app` (Compose). فلیورهای `cafebazaar`/`myket` از روز اول (فعلاً بدون
  تفاوت - SDK پرداخت/تبلیغ هر استور تو فاز ۴ به فلیور خودش اضافه می‌شه).
- **تقویم جلالی**: همون الگوریتم Borkowski/jalaali-js تاییدشده‌ی «وام من» (تست‌شده در برابر
  jdatetime، شامل کبیسه‌های ۱۴۰۳/۱۴۰۸) - `core/JalaliCalendar.kt`.
- **زبان طراحی شیشه‌ی دولایه** (`ui/glass/Glass.kt`):
  - `AuroraGlassBackground`: پس‌زمینه‌ی شبِ سرمه‌ای + دو هاله‌ی نور متحرک (فیروزه‌ای/طلایی). رو
    Android 12+ هاله‌ها `Modifier.blur` (RenderEffect واقعی) می‌گیرن؛ رو پایین‌تر blur خودکار no-op
    می‌شه و همون گرادیان شعاعی نرم می‌مونه - fallback بدون کد شرطی، و blur هیچ‌وقت تو مسیر اسکرول نیست.
  - `GlassCard`: سفیدِ نیمه‌شفاف گرادیانی + حاشیه‌ی روشن لبه‌ی بالا (بازتاب نور شیشه) - بدون blur.
- **صفحه‌ی اصلی تقویم**: سربرگ امروز (شمسی درشت + میلادی + قمری + بج مناسبت)، پیجر بی‌نهایت ماه‌ها
  (سوایپ)، گرید ماه با حلقه‌ی گرادیانی دور امروز، جمعه/تعطیل قرمز، نقطه‌ی مناسبت زیر روز، پنل روز
  انتخاب‌شده.
- **اعلان دائمی + «عدد بالای گوشی»** (`notif/DayNotification.kt`): عدد فارسی روز به‌صورت بیت‌مپِ
  رندرشده در لحظه به‌عنوان smallIcon نوار وضعیت (جایگزین درست اندرویدیِ بجِ iOS - نه ۳۱ فایل آیکون).
  محتوا: تاریخ سه‌گانه + مناسبت، با شخصی‌سازی کامل تو تنظیمات (روشن/خاموش، مینیمال، هر خط جدا).
  به‌روزرسانی: آلارم نیمه‌شب (exact اگه مجاز، وگرنه پنجره‌ی ۱۰دقیقه‌ای) + بوت + تغییر ساعت/منطقه +
  آپدیت اپ + هر بازشدن اپ - همه از `notif/DateChangeReceiver.kt`.
- **قمری**: از ICU خود اندروید (`android.icu`، ام‌القری) - بدون کتابخونه‌ی اضافه؛ ممکنه با اعلام
  رؤیت هلال ایران ±۱ روز اختلاف داشته باشه (برای فاز ۲ اگه تعطیلات قمری اومد باید جدول رسمی بشینه).
- **دو ویجت Glance** (`widget/`): «امروز» (عدد درشت + مناسبت) و «ماه کامل» (گرید با امروزِ برجسته) -
  پس‌زمینه‌ی شیشه‌ای drawable، کلیک = بازشدن اپ، آپدیت push از همون مسیر نیمه‌شب. (دو ویجت دیگه‌ی
  پرامپت - «امروز+رویدادها» و «ساعت+اوقات شرعی» - به‌ترتیب به داده‌ی فاز ۲ و موتور اذان فاز ۳ نیاز
  دارن و با همون‌ها میان.)
- **آنبوردینگ/اینترو** (`ui/onboarding/`): لوگوی زنده‌ی اختصاصی (حلقه‌ی گرادیانی چرخان + عدد امروز)،
  و گرفتن اجازه‌ها با توضیحِ «چرا»: اعلان (۱۳+)، خروج از بهینه‌سازی باتری، و دکمه‌ی تنظیمات «اجرای
  خودکار» مخصوص برند (شیائومی/اوپو/ویوو/هواوی/آنر). ردکردن هر اجازه اپ رو نمی‌شکنه.
- **موتور افکت روزهای خاص** (`ui/effects/ParticleOverlay.kt`): data-driven از `core/Occasions.kt` -
  شکوفه (نوروز/سیزده‌به‌در)، برف (شروع زمستون)، ستاره‌ی چشمک‌زن (یلدا/سده/سپندارمذگان)، برگ پاییزی
  (مهرگان). Canvas خالص، موقعیت ذره‌ها تابع قطعی زمان (صفر تخصیص per-frame)، ~۶۰ ذره، بدون blur -
  و کلید خاموش‌کردن تو تنظیمات.
- **فونت**: وزیرمتن (۴ وزن، `res/font/`). **آیکون**: تولیدشده (سرمه‌ای + حلقه‌ی فیروزه‌ای→طلایی +
  «۳۱»)، legacy برای API 24-25 و adaptive برای 26+.

### ⏳ فاز ۲ - داده و رویدادها (شروع نشده)
مناسبت‌های ۳لایه (رسمی/باستانی/میلادی، هرکدوم جدا روشن/خاموش) با JSON باندل + آپدیت از راه دور
(تقویم رسمی هر سال عوض می‌شه!)، تعطیلات قمری با جدول رسمی، رویدادهای کاربر (تولد/سالگرد، Room +
تکرار شمسی + یادآوری چندمرحله‌ای)، و آینه‌سازی به CalendarProvider گوشی (سینک خودکار گوگل، بدون
OAuth - رو گوشی بدون Play Services هم کار می‌کنه؛ اجازه‌ی تقویم همون‌موقع گرفته می‌شه).

### ⏳ فاز ۳ - اذان و والپیپر (شروع نشده)
اوقات شرعی آفلاین (ژئوفیزیک تهران پیش‌فرض + MWL/ISNA/...، تنظیم دقیقه‌ای هر وقت، مؤذن انتخابی)،
والپیپر زنده (ساعت + تاریخ + هوا).

### ⏳ فاز ۴ - انتشار و درآمد (شروع نشده)
تبلیغ تپسل/آدیوری پشت interface مشترک (بازار/مایکت شبکه‌ی تبلیغ ندارن)، اشتراک حذف تبلیغ
(Poolakey / myket-billing-client per-flavor)، آپدیت اجباری (minVersionCode از JSON راه دور).

## بیلد و تست
- **تو سندباکس فقط `:core` قابل تست/تاییده** (اندروید به dl.google.com نیاز داره که مسدوده). چون
  configure کردن پروژه‌ی اصلی AGP رو می‌خواد، تست core از یه هارنس جدا اجرا می‌شه که فقط `:core` رو
  include می‌کنه (یه settings.gradle.kts موقت با `project(":core").projectDir = ...` - رجوع کن به
  تاریخچه‌ی چت سازنده).
- **بیلد کامل APK فقط از CI**: `.github/workflows/build-roozegar.yml` (چهار APK: دو فلیور ×
  debug/release + تست core). versionCode/versionName از `github.run_number`.
- امضای debug همون `ci-debug.keystore` ریشه‌ی ریپوئه (مشترک با «وام من» - فقط برای نصب تستی).
  **کلید release این اپ باید جدا ساخته بشه** (سکرت‌های `ROOZEGAR_KEYSTORE_BASE64` و ...) - بعد از
  اولین انتشار دیگه قابل عوض‌کردن نیست، و درسِ Play Protect پروژه‌ی قبلی: applicationId
  (`ir.sadteam.mycalendar`) و کلید امضا رو بعد از ارسال به استور دست نزن.

## نکته‌های فنی که نباید فراموش بشن
- «عدد بالای گوشی» = smallIcon بیت‌مپیِ رندر runtime تو `DayNotification.renderDayIcon` - نوار
  وضعیت فقط آلفا رو می‌بینه (سیلوئت سفید)، پس متن سفید رو شفاف دقیقاً درسته.
- اعلان دائمی foreground service **نیست** (نیازی نیست و باتری/سیاست استورها رو درگیر نمی‌کنه) -
  یه notification با ongoing=true که از آلارم/رسیور تازه می‌شه. رو بعضی OEMها کاربر می‌تونه ببندش؛
  با بازشدن بعدی اپ/نیمه‌شب برمی‌گرده.
- تم v1 عمداً فقط تیره‌ست (شیشه رو تیره بهترین جلوه رو داره - مثل خود روزگار)؛ تم روشن بک‌لاگ.
- تو RTL، آیکون فلش «راست» = ماه قبل. پیجر با ایندکس سریالی ماه (`MonthGrid.indexOf`) کار می‌کنه،
  نه چپ/راست بصری.
- `Occasions.fixedJalali` فقط مناسبت‌های شمسیِ ثابته - **کامل نیست** و تعطیلات قمری نداره؛ گرید
  فعلاً فقط جمعه + تعطیلات ثابت رو قرمز می‌کنه (درست ولی ناقص - فاز ۲ کاملش می‌کنه).
